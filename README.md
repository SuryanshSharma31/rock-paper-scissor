# Rock Paper Scissors 🎮

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The game allows the player to choose Rock, Paper, or Scissors and compete against the computer.

## 🚀 Live Demo

🔗 **[Play Rock Paper Scissors](https://rock-paper-scissor-sigma-nine.vercel.app/)**

## ✨ Features

* 🎮 Play against the computer
* 🪨 Rock, 📄 Paper, and ✂️ Scissors choices
* 📊 Tracks player and computer scores
* 🔄 Reset button to restart the game
* 💻 Simple and interactive user interface
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling and layout
* **JavaScript** – Game logic and user interaction

## 🎯 How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects its move.
3. The winner is decided according to the following rules:

   * Rock beats Scissors
   * Scissors beats Paper
   * Paper beats Rock
4. The score is updated after every round.
5. Use the **Reset** button to start a new game.
